Simulador em `scripts/bot-sim/` (README lá) roda os Code nodes reais + API interna real; relatório em `docs/qa/auditoria-bot-2026-09-30.md`.

Áreas frágeis (priorizar em regressão): confirmação/`Interpretar` só casa número ou prefixo de rótulo (sem sim/ok/👍); passo de nome aceita qualquer texto; HTTP nodes GET sem neverError => cliente sem resposta em 404/5xx; paginação (`nextFrom` inclusivo, numeração 9 fixa, cíclica); SLOT_TAKEN sem data; prazo de cancelar/remarcar só no fim; textos editáveis do MAIN_MENU desacoplados da ação; `dateISOToUtcNoon` erra o dia em fuso >= +12.

Armadilhas de ambiente: `innochat_test` é compartilhado e os testes de integração sobrescrevem o segredo interno (usar banco dedicado `innochat_botsim`); `next build` pisa na `.next` do `next dev` (usar git worktree); Turbopack recusa node_modules como junction (usar `--webpack`); Prisma Client compartilhado em node_modules pode vir de outro branch (P2022, googleAuthEnabled) => gerar client próprio no worktree; heredoc do Bash quebra com scripts grandes (usar Write).
